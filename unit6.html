Finished

Quick rules

Regular verbs: add -ed (work → worked). Check spelling: study → studied, stop → stopped.

Irregular verbs: learn them: go → went, have → had, see → saw, buy → bought, write → wrote.

Negative and questions: didn't / Did + base verb (He didn't like it. Did you work?)

Time words: yesterday, last week, two years ago, in 2001.

however = contrast · when = time · until = up to a time · so = result
